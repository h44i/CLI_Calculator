# CLI_Calculator
## `I.` Функционал
Консольный калькулятор, который вычисляет арифметические выражения и выполняет перевод единиц измерения.

Поддерживаются:

* целые и дробные числа, в том числе такие форматы записи: `0.1`, `.1`, `1.0`, `1.` 

* сложение `+`, вычитание `-`, умножение `*`, деление `/`, целочисленное деление `//`, остаток от деления `%`, унарные `+` и `-`

* перевод чисел в единицах измерения: `g` <-> `kg` | `c` <-> `f` <-> `k` | `mm` <-> `cm` <-> `m` <-> `km`

Программа проверяет введенное выражение и обрабатывает основные ошибки: недопустимые символы, неправильную структуру выражения и деление на ноль.

Для вычислений используется Decimal с точностью 10 значащих цифр и округлением ROUND_HALF_UP. Это позволяет избежать проблем с точностью, которые могут возникать при использовании float для десятичных чисел. В результате значения выводятся в float

## `II.` Запуск программы
Перейти в папку программы:

```
cd [path]
```

Создание виртуального окружения:
```
python -m venv .venv

.venv\Scripts\activate

python -m pip install -e ".[test]"
```
Запуск используя команды:

```
python -m toolkit calc "EXPRESSION"
```
```
python -m toolkit convert VALUE --from UNIT --to UNIT
```
## `III.` Алгоритм

Сначала программа разбирает введенное выражение на отдельные части с помощью регулярных выражений. Получается список токенов, в котором отдельно находятся числа и операторы.

`2 + 3 * 4`

Преобразуется в:

`['2', '+', '3', '*', '4']`

Если программа встречает последовательность вида: **оператор[1] -> оператор[2] -> число**, и оператор[2] равен `+` или `-`, то он считается унарным. В таком случае два элемента **оператор[2] -> число** объединяются в один.

`['2', '+', '3', '*', '-', '4']`

Преобразуется в:

`['2', '+', '3', '*', '-4']`

После этого программа проверяет полученный список на правильность выражения.

Чтобы сохранить приоритет операций, сначала выполняются `*`, `/`, `//` и `%`. При нахождении такого оператора три элемента **число → оператор → число** заменяются на результат операции.

`['2', '+', '3', '*', '4']`

Преобразуется в:

`['2', '+', '12']`

После этого таким же способом выполняются операции `+` и `-`:

`['2', '+', '12']`

Преобразуется в:

`14.0`

### Конвертер

Конвертер сначала определяет, к какой группе относится исходная и конечная единица: длина, масса или температура.

Для длины и массы используются коэффициенты относительно базовой единицы. Сначала значение умножается на коэффициент исходной единицы, после чего делится на коэффициент конечной:

`100 --from mm -to m` -> `100 * 0.001 / 1.0` -> `0.1`

Для температуры сначала выполняется перевод в градусы Цельсия, а уже потом в нужную единицу. Также перед переводом проверяется абсолютный ноль:

`20 --from c --to f` -> `(20 * 9/5) + 32` -> `68.0`
