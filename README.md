# CLI_Calculator
## `I.` Функционал
Консольный калькулятор для вычисления арифметических выражений и конвертаций единиц измерений.

Поддерживаются:

* целые и дробные числа включая форматы записи: `0.1`, `.1`, `1.0`, `1.` 

* сложение `+`, вычитание `-`, умножение `*`, деление `/`, целочисленное деление `//`, остаток от деления `%`, унарные `+` и `-`

* перевод чисел в единицах измерения: `g` <-> `kg` | `c` <-> `f` <-> `k` | `mm` <-> `cm` <-> `m` <-> `km`

Программа проверяет корректность входного выражения и обрабатывает ошибки на: недопустимые символы, некорректную структуру выражения и деление на ноль.

Для вычислений используется Decimal с точностью 10 значащих цифр и округлением ROUND_HALF_UP, что позволяет избежать ошибок точности при работе с десятичными числами через float. Вывод значений в float.

## `II.` Запуск программы
Перейти в папку программы:

```
cd [path]
```

Создание виртуального окружения:
```
python -m venv .venv

.venv\Scripts\activate

python -m pip install -e ".[test]"
```
Запуск используя команды:

```
python -m toolkit calc "EXPRESSION"
```
```
python -m toolkit convert VALUE --from UNIT --to UNIT
```
## `III.` Алгоритм

### Калькулятор

Для вычисления выражения программа сначала выполняет токенизацию, используя регулярные выражения, преобразует строку в список отдельных токенов, разделяя на числа и операторы.

`2 + 3 * 4`

Преобразуется в:

`['2', '+', '3', '*', '4']`

Если программа замечает последовательность токенов вида: **оператор[1] -> оператор[2] -> число** и оператор[2] `+` или `-`, программа понимает, что оператор[2] унарный знак и два элемента **оператор[2] -> число** заменяются на один элемент.

`['2', '+', '3', '*', '-', '4']`

Преобразуется в:

`['2', '+', '3', '*', '-4']`

После токенизации выполняется проверка корректности выражения.

Для соблюдения приоритета операций, программа сначала обрабатывает операторы `*`, `/`, `//` и `%`. При нахождении такого оператора: три элемента **число → оператор → число** заменяются одним элементом.

`['2', '+', '3', '*', '4']`

Преобразуется в:

`['2', '+', '12']`

Затем таким же способом обрабатываются операции `+` и `-`:

`['2', '+', '12']`

Преобразуется в:

`14.0`

### Конвертер

Конвертер определяет группу исходной и конечной единицы: длина, масса или температура.

Для длины и массы используются коэффициенты относительно базовой единицы. Значение умножается на коэффициент исходной единицы и делится на коэффициент конечной:

`100 --from mm -to m` -> `100 * 0.001 / 1.0` -> `0.1`

Для температуры значение сначала переводится в градусы Цельсия, а затем из Цельсия в нужную единицу. Перед этим проверяется абсолютный ноль:

`20 --from c --to f` -> `(20 * 9/5) + 32` -> `68.0`
